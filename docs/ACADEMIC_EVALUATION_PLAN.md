# Academic evaluation plan

## Research questions

1. How closely does MedSim deterministic scoring agree with two clinician raters?
2. Does repeated MedSim practice improve performance on unseen reviewed cases?
3. How faithfully does the optional local model explain recorded evidence?
4. Can learners complete the workflow efficiently and accessibly?

## Proposed study

- Pre-register hypotheses, primary outcomes, exclusions, and analysis.
- Obtain supervisor and institutional ethics guidance before recruiting people.
- Use a pre-test/post-test design with unseen cases and an appropriate comparison
  condition where feasible.
- Record case version, rubric version, scoring version, timing, and event log.
- Blind clinical raters to automated scores where practical.
- Report inter-rater agreement and automated-to-clinician error by domain.
- Collect usability, task completion, cognitive load, and qualitative feedback.
- Report missing data, selection bias, learning effects, and limited generality.

## Engineering evidence submitted with the dissertation

- Requirements traceability matrix.
- Architecture decisions and threat model.
- Automated test and accessibility reports.
- Clinical review ledger and reference manifest.
- Model card, benchmark protocol, raw aggregate results, and failure examples.
- Reproducible build/deployment instructions and a dependency/license inventory.
- Explicit separation of technical integrity, clinical validity, and educational
  effectiveness.
