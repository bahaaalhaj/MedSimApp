# Project overview

MedSim is an outpatient-only browser simulation with 24 specialties, a Three.js consultation room, versioned synthetic cases, investigation and prescription workflows, authenticated/guest history, and AI-supported debriefing.

Learners communicate through typed or prepared questions. Patient replies are durable text with optional local Kokoro speech. Chatterbox is feature-gated. Audio failure is non-blocking and cannot invalidate the transcript.
